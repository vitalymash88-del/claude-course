# Claude Course

A hands-on workspace for learning to build with Claude, Anthropic's AI assistant. It collects course notes, exercises, and example projects.

## Contents

| Section | Description |
| --- | --- |
| `notes/` | Lesson notes and key concepts |
| `exercises/` | Practice tasks for each module |
| `projects/` | Larger example projects built during the course |

> These directories don't exist yet. Create them as the course goes on, and update this table to match.

## Topics

- Prompting basics: clear instructions, examples, and structured output
- Using the Claude API and the Anthropic SDKs
- Tool use and building agents
- Working with Claude Code for software development

## Getting started

1. Clone the repository:

   ```bash
   git clone https://github.com/vitalymash88-del/claude-course.git
   cd claude-course
   ```

2. If you'll call the Claude API, get an API key from the [Claude Console](https://console.anthropic.com/) and set it as an environment variable:

   ```bash
   export ANTHROPIC_API_KEY="your-api-key"
   ```

   Never commit API keys to the repository.
